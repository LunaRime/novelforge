# NovelForge UX 修复实施计划（分块执行）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 2026-08-06 用户视角 UX 审查发现的问题，分 6 块（A-F）逐块交付，每块独立可验证、可提交。

**Architecture:** 全部为渲染进程 UI 改动，不涉及 DB schema / IPC 通道变更。块 A-C 为低风险点状修复（门控、文案、行为），块 D 为组件合并（删死代码、统一 API），块 E 为设置重构（模型管理合一 + 补齐隐藏功能 UI），块 F 为信息架构收敛（视图合并、入口收敛）。每块完成后跑完整质量门禁并单独提交。

**Tech Stack:** Electron 41 + React 19 + TypeScript 6 + Vite 8 + Zustand + Tailwind CSS 4 + Radix

## Global Constraints

- 质量门禁三件套必须全绿：`pnpm run typecheck` / `pnpm run lint`（--max-warnings 0）/ `pnpm run test`（现有 274 个测试不得回归）
- **三语同步**：所有新增/修改的用户可见文案必须同时更新 `src/shared/locale-data.ts` 的 `zh-CN` / `en-US` / `ru-RU` 三个字段；禁止硬编码中文
- TypeScript strict（noUnusedLocals / noUnusedParameters）；删除文件后必须清除全部引用，不留孤儿 import
- 禁止硬编码颜色，一律 `var(--color-*)`；新加 UI 复用现有组件（Button/Confirm/toast 等）
- 提交信息遵循仓库惯例：`fix: <中文描述>` / `feat: <中文描述>`，每块一个提交，不推送
- 涉及删除文件时，先 grep 确认无引用（含 stories/ 与测试文件），同步删除对应 .stories.tsx / .test.tsx
- locale.test.ts 会校验 key 唯一性与三语完整性——新增 key 必须三语齐全，删除 key 要同步删干净

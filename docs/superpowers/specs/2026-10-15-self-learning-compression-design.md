## 0. 结论摘要

| 方法 | 核心机制 | 对 NovelForge 的裁决 |
|---|---|---|
| **TACO**（终端 Agent 压缩） | 免训练规则引擎：从真实轨迹中**发现 / 精炼 / 复用**结构化压缩规则（触发条件 + 保留模式 + 剔除模式），全局规则池跨任务迁移 | ✅ **采纳其架构形状**。v1 以「固定规则目录 + 统计自适应」落地（零新增 LLM 调用）；LLM 合成候选规则列为 v2（需过成本审阅） |
| **Accordion-Thinking**（手风琴式思考） | **RL 训练**模型周期性自折叠推理链，学习推理粒度自我调节 | ❌ 不引入。需要模型权重与训练管线，NF 使用外部 API + Ollama，无训练权；仅借鉴「固定粒度分节」→ 已由加固计划 P1-1 落实 |
| **Agent-Omit**（选择性省略） | 冷启动微调 + 省略感知 RL，训练 Agent 省略冗余思考/观察 | ❌ 不引入（同训练依赖）。借鉴「选择性省略」思想 → 落为 v1 的 omit 类规则（省略对象是工具噪声，不是模型思考） |
| **Cartridges**（自学习 KV 缓存） | 针对语料**离线训练**压缩 KV 缓存，用上下文蒸馏复现 ICL 能力 | ❌ 不引入。需推理栈内部（KV 缓存 / logits）访问权与训练设施，NF 两者皆无；列入明确不做 |

一句话：**NF 唯一可移植的是 TACO 式的「无训练信号反馈环」**——其余三者的机制前提（训练模型/访问推理栈）在桌面应用 + 外部 LLM 的架构下不成立。v1 把「学习」限定在三个对象上：**何时压（时机）、保什么（内容）、略什么（省略）**，全部由已有事件统计驱动，默认关闭、可整体重置。

## 1. 现状：可挂载面盘点

NF 压缩链（CCR）已具备的能力与空缺（截至本次加固前）：

| 面 | 现状 | 对自学习是否够用 |
|---|---|---|
| 压缩事件源 | `agent-store.sendMessage` 超预算触发；批次选择 `selectCompressionBatch` | ✅ 每个压缩事件有明确的 before/after 数字 |
| 策略旋钮 | `compaction-prefs`：budgetPercent / historyMaxTokens / minimumChangeTokens / keepBatches（用户偏好，只影响之后的压缩） | ✅ 时机学习的合法调节面 |
| 可逆性 | 分卷原文永不丢（revert / 重生成 / 展开恢复） | ✅ 「用户移除压缩」可作为强负反馈信号 |
| 可证明性 | 降幅断言（changeTokens < minimumChangeTokens 则跳过） | ✅ 跳过事件 = 低增益信号 |
| 保真监督 | **本次加固新增**（P1-2 实体保留率检查） | ✅ v1 学习的核心监督信号 |
| 写错留痕 | 跳过留痕（renderLog）；**本次加固新增**硬截断留痕（P0-2） | ✅ 截断事件 = 压缩不足信号 |
| 摘要结构 | **本次加固新增**固定分节 + 分节裁剪（P1-1） | ✅ 保真检查可按分节对齐 |
| 观测面 | **本次加固新增**实发口径 + 前缀记账接线（P0-1） | ✅ 成本/命中可见 |

> ⚠️ 结论：**引入自学习不需要新机制，只需要把上述信号喂给一个本地规则池**——这也是本方案不做任何训练、不新增 LLM 调用的底气。

## 2. 四方法评估矩阵（维度化）

评估维度：①是否需要训练/权重访问 ②是否需要额外 LLM 调用 ③NF 现有信号能否支撑 ④失败时的可回滚性 ⑤实现与维护成本。

| 维度 | TACO | Accordion-Thinking | Agent-Omit | Cartridges |
|---|---|---|---|---|
| 训练依赖 | 无（免训练，但规则合成依赖外部 LLM） | **RL 训练**（模型权重） | **微调 + RL** | **离线训练 KV 缓存**（权重/logits） |
| 推理栈访问 | 不需要 | 需要（KV 缓存/推理循环） | 不需要（但需模型可训练） | **需要**（KV 缓存注入） |
| 额外 LLM 调用 | 有（规则合成，低频） | 无（训练折进权重） | 无 | 无（训练折进缓存） |
| NF 信号支撑 | ✅ 压缩事件 + 保真 + 回退 + 截断 | ❌ 无推理链训练数据 | ⚠️ 需标注「省略安全」样本 | ❌ 无 |
| 可回滚性 | ✅ 规则可停用/重置，不碰历史 | ❌ 权重改动不可单点回滚 | ❌ 同 | ❌ 同 |
| 成本 | 低（v1 零 LLM） | 高（训练 + 评测） | 高 | 高（每语料训练） |
| 裁决 | **采纳（形状）** | 不引入 | 不引入 | 不引入 |

补充说明：

- **TACO 的完整闭环**（公开资料核实）包含三段：任务内规则演化（发现 → 精炼 → 退役）→ 全局规则池（跨任务迁移）→ 过压信号（Agent 重复请求完整输出/重复命令时退役规则）。NF 的对应物：**活动规则集 → config 持久化池 → 保真缺失/用户移除压缩/重生成**。映射关系完整，说明形状可移植。
- **Accordion-Thinking / Agent-Omit** 的价值在于「证明了持续学习压缩不会必然降智」——这一结论对 NF 的启示是：**压缩质量的回归要靠反馈信号兜住**（P1-2 保真检查 + v1 规则退役），而不是靠模仿它们的训练方式。
- **Cartridges** 的 38.6× 内存缩减来自模型内部表示训练，属于「模型提供商侧」的能力；NF 作为应用层无法也不应复制。若未来 NF 接入可控的本地小模型推理栈，可重新评估。

## 3. 采纳方案：TACO 式本地压缩规则引擎（v1）

### 3.1 学习对象（三问）

| 学习对象 | 问题 | 调节面 | 信号 |
|---|---|---|---|
| **时机** | 何时压 / 压多狠 | `effectiveMinimumChange = clamp(用户值 × 倍率, 0, 2000)`，倍率 ∈ [0.5, 1.5] | 跳过（无收益）→ 收紧；压缩后仍被硬截断 → 放宽；正常成功 → 向 1.0 缓慢回中 |
| **内容** | 保什么 | 摘要 prompt 追加「保留规则」提示（写库目标 / 角色名 / 章节号） | P1-2 保真检查的**缺失类别**累计 ≥2 → 激活规则；激活后继续缺失 ≥3 → 退役（提示无效） |
| **省略** | 略什么 | 摘要 prompt 追加「省略规则」提示（重复读取与中间进度可略） | 低增益压缩（降幅比 <15%）累计 ≥3 → 激活；激活后出现保真告警 ≥2 → 退役 |

### 3.2 规则池与生命周期

```
证据累积（inactive） ──达到门槛──▶ 激活（active，进入摘要 prompt）
        ▲                                   │
        └──重新累积（+2 证据）── 退役 ◀──反证达到门槛──┘
```

- 规则目录**固定**（v1）：`keep-write-targets` / `keep-characters` / `keep-chapter-refs` / `omit-read-noise`。规则文本是 i18n 键（跟随界面语言进 prompt），**不是自由文本生成**——可审计、可回滚、零注入风险。
- 每条规则记 `evidence`（支持证据）/ `backfire`（激活后的反证）/ `evidenceAtLastDecision`（防止退役后立即复活）。
- 全部状态变更（激活/退役/倍率调整）经 `renderLog('info', 'Agent', …)` 留痕 → LogsView 可回放「学习器什么时候改了什么」。

### 3.3 信号源（全部零 LLM 成本）

| 信号 | 来源 | 语义 |
|---|---|---|
| 保真缺失类别 | P1-2 `ccr-fidelity` 报告 | 该类别实体被摘要丢掉 |
| 硬截断条数 | P0-2 裁剪循环计数（同轮） | 压缩不足（上下文真的丢了） |
| 跳过 | B2 降幅断言 | 压缩无收益（浪费一次摘要调用） |
| 用户移除压缩 | `removeCompaction` | 强负反馈（v1 只统计，不自动动作——移除动机多样，避免误伤） |
| 用户重生成摘要 | P1-3 `regenerateBatchSummary` | 弱负反馈（v1 只统计） |

> 与加固计划 §4.1 一致：**不引入 LLM-as-judge**。所有信号都来自已发生事件的算术，不需要额外判据模型。

### 3.4 应用面（保守边界）

1. **摘要 prompt 附加提示**：只追加规则文本（在既有 `ccr.summaryPrompt` 之后、批文本之前），不改动既有指令与批文本本身。
2. **最小降幅阈值倍率**：只作用于 `minimumChangeTokens` 的**判定**，不写回用户偏好值（`config.compaction` 不动，倍率存在独立键）。
3. **不改写历史、不重算已压批次、不重生成摘要**——与 `compaction-prefs` 同语义：只影响之后的压缩。

### 3.5 存储与开关

- 独立顶层配置键 `compactionLearning`（**不与 `compaction` 同键**：`config:set` 是顶层浅合并，设置页保存 `compaction` 时不得覆盖学习状态）。
- 设置页「上下文与压缩」分区新增子卡：**开关（默认关闭）** + 统计行（压缩 N 次 / 跳过 / 截断 / 保真告警 / 移除 / 激活规则数）+ **重置学习数据**按钮。学习控件改动经同一「保存」按钮落盘；未触碰时保存不写该键（避免用陈旧统计覆盖实时学习结果）。
- 关闭（默认）时行为与引入前**逐字一致**：不读不写 `compactionLearning`，不追加提示，阈值用用户原值。

### 3.6 防漂移与安全阀（对应「规则漂移」风险）

| 阀 | 机制 |
|---|---|
| 有界 | 倍率钳制 [0.5, 1.5]；有效阈值沿用 [0, 2000] 钳制；规则数固定 ≤4 |
| 门槛 | 激活需 ≥2 证据；退役需 ≥3 反证；退役后需新增 ≥2 证据才可复活（防抖） |
| 留痕 | 所有决策 renderLog + 统计可见；全部可解释为「谁、何时、因为哪条证据」 |
| 重置 | 一键清空全部学习数据（回默认态） |
| 版本 | 状态含 `version` 字段，形状破坏时整段回默认（fail-safe） |
| 作用域 | v1 全局单池（规则是**类别级**的，天然跨项目通用；项目级分池列 v2） |

## 4. 取舍分析（决策记录）

| # | 议题 | 选项 | 取舍 | 裁决 |
|---|---|---|---|---|
| 1 | 训练 vs 免训练 | 移植 Accordion/Omit/Cartridges 的训练思路 / 只做免训练反馈环 | 训练路线：NF 无权重、无 GPU、不可回滚、用户设备不一；免训练路线：收益上限低但零风险、可解释 | **免训练** |
| 2 | 规则来源 | LLM 合成规则（TACO 完整形态）/ 固定目录 + 统计自适应 | LLM 合成：更贴原论文，但引入低频额外调用 + 规则质量不可预审；固定目录：能力弱一点，但零成本、可审计 | **固定目录（v1）**；LLM 合成列 v2 |
| 3 | 学习作用点 | 直接改写摘要/批次内容 / 只调提示与阈值 | 直接改写有质量与可复现风险（用户无法审阅改了什么）；调提示让 LLM 保留最终判断权 | **只调提示与阈值** |
| 4 | 默认开关 | 默认开 / 默认关 | 默认开：老用户行为悄然改变（违反「只影响之后的压缩 + 用户可控」哲学）；默认关：收益需用户显式开启 | **默认关** |
| 5 | 信号范围 | 引入 LLM 评判或用户星级 / 只用结构事件 | LLM 评判成本随轮次线性上升且判据不稳（加固计划 §4.1 已否）；结构事件零成本、方向明确 | **只用结构事件** |
| 6 | 作用域 | 全局池 / 项目池 / 会话池 | 项目池更贴切但配置与迁移复杂；会话池记不住；类别级规则全局通用 | **全局池（v1）** |
| 7 | 更新时机 | 每次请求都评估 / 仅压缩相关事件 | 每请求评估会放大噪声并频繁写盘；压缩事件本身低频（几十轮一次） | **事件驱动、稀有写盘** |
| 8 | 与「可逆」承诺的关系 | 学习可否引发新的删除 | 任何学习都不得删除原文/批次——保留 B 档「原文永不删」契约 | **学习只碰提示与阈值** |

## 5. 风险对照（用户所列四风险 → NF 本地方案）

| 风险 | 在 NF 的对应形态 | 应对 |
|---|---|---|
| **灾难性遗忘** | 非参数系统（规则池是计数与布尔），不存在权重遗忘；等价风险是**规则被错误退役/反复横跳** | 迟滞门槛（激活 2 / 退役 3 / 复活 +2）+ `evidenceAtLastDecision` 防抖 + 全量重置；EWC/SDFT 类技术对非参数系统不适用（写明理由，避免照搬） |
| **规则漂移与收敛** | 倍率/规则随时间偏离有效区 | 有界钳制 + 回中机制（成功时向 1.0 收敛）+ 事件驱动（稀有更新）+ 决策留痕；v2 可加「相邻窗口规则保留率」作为收敛信号（TACO 的 Retention 指标同款思路） |
| **训练成本与复杂性** | 本方案零训练、零新增 LLM 调用 | 无新增部署依赖；成本 = 本地几次 JSON 读写 |
| **评估困难** | 「真的更好吗」未知 | v1 内建指标（跳过率/截断率/保真率/移除率，设置面板可见）；诚实边界：**v1 不声称效果提升，只提供自适应与可观测**；v2 做开关影子对照（记录假设性动作，不改行为） |

## 7. 非目标（v1 明确不做）

1. 不训练任何模型 / 不微调 / 不访问推理栈内部。
2. 不做 LLM 合成规则、不做 LLM-as-judge（列 v2 评估）。
3. 不做跨用户/云端的规则共享（NF 无服务端，且涉及隐私）。
4. 不自动删除压缩批次或分卷原文（维持「原文永不删」）。
5. 不自动重生成摘要（重生成保持用户显式触发）。

## 8. 验收与测试口径

- **单元**（`compression-learning.test.ts`）：坏形状回默认；倍率边界（0.5/1.5 钳制、回中）；跳过/截断/成功三类更新的方向与幂等；规则激活/退役/复活门槛；提示组合只含激活规则；重置。
- **集成**（`agent-store.test.ts`）：开启后压缩路径把激活规则提示注入摘要 prompt（检查 LLM 调用实参）+ 事件后 `config:set compactionLearning` 被写入；**关闭（默认）时不写、不注入、阈值逐字等于用户值**。
- **保真回路**：P1-2 缺失类别 → 规则的 evidence 增长（同一条用例断言两处）。
- **设置**：开关/重置可保存；未触碰学习控件时保存不写 `compactionLearning`（防陈旧覆盖）。

## 9. 路线图（v2 候选，不进本次范围）

1. **影子对照**：学习器记录「如果启用会做什么」（不执行），设置页展示对照统计 —— 直接回应「评估困难」。
2. **LLM 合成候选规则**：仅当出现未被固定目录覆盖的反复损失模式时，用 budget 档模型生成候选规则文本，人工可审后入池（把 TACO 的 discoverer 补齐）。
3. **项目级分池**：`compactionLearning` 增补 `byProject` 维度（需要评估配置体积）。
4. **收敛指标**：规则保留率（相邻窗口 top-K 重叠）+ 指标报表（跳过率/截断率趋势）。

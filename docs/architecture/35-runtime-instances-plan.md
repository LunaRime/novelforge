- [x] Agent 真实循环接受实例工具目录与执行依赖。裸 JSON 识别、工具查找和未知工具提示共用目录，审批与结果使用本次循环的回调。父子任务从应用组合捕获端口，工具也能接受独立目录和端口。
- [x] 项目、编辑器、工具、技能、记忆和 RAG 上下文使用传入实例。内置工具在入口绑定端口，延迟后再次调用 IPC 前核对来源；文件读去重按实例与项目会话保存。重新安装默认端口后，正在运行的目录范围调用仍留在原实例。
- [x] 现有工作流循环由 `createWorkflowRuntime` 构造。等待 resolver、活动运行、流式缓冲和恢复定义归属实例。完成事件、输出、checkpoint 和恢复工厂通过传入端口访问。现有 renderer store 负责接入项目、Electron、界面和应用事件。
- [x] 两个实例从真实 Agent 与工作流入口并行执行。测试覆盖取消等待审批、工具超时和异常、另一方审批和结果顺序、同 runId 的输出与事件隔离、等待断点写入，以及同路径新会话收到旧工作流完成时的 checkpoint 保护。
- [x] 2026-11-13 本地验收。全量 352 个测试文件、3,867 条测试通过，单跑契约 12 条通过。全量 TypeScript、core 独立编译、ESLint 零警告、架构边界 0/0/0、Vite 生产构建和公开产物审计通过。

默认 5 秒的本地复跑有一条既有 LanceDB 回填测试超时，最终全量复跑通过命令行设置 `--testTimeout 15000`，仓库测试配置沿用原值。下一批 D4 验证无 UI 创作业务链路。

工具超时结束本轮等待，工具自身是否支持中止取决于其执行端口。应用仍以自己的事件总线、动态工具目录和持久化适配器组合默认实例。独立引擎打包及文件存储切换各有后续验收。

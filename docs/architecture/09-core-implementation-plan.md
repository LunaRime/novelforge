## 本轮设计

文件存储、元数据索引和用例通过接口连接。核心不依赖 Electron、React、Zustand 或现有 stores。章节文件只用序号命名，id 保存在 frontmatter；文件是事实源，索引损坏可以重建。保存使用原子写、历史快照、独占锁和内容 hash 并发校验，失败不回退到 DB。

迁移读取旧库副本，完整保留归档、分支、修稿和审稿的原始数据，不自动剪断旧读写路径。遇到不支持的数据或冲突应拒绝导出并给出报告；完成后逐项比对正文 hash，重复执行不得覆盖外部编辑。旧版无法识别新版本标记，因此不能把新增标记宣传为已发布旧版的降级保护。

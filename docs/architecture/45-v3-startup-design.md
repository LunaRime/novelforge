# V3 启动画面设计与接入

把应用打开后的第一屏做成一张置中的稿纸。用 V3 的暖白或深色画布、折页 N 与一条苔绿色的等待指示线承接欢迎页和工作台。加载页保留品牌和实际状态。打开评审样板可切换两种外观、三种语言和三种状态。[启动画面样板](../ui-redesign-v3/startup.html)

## 状态与交互

| 状态 | 画面 | 接入条件 |
| --- | --- | --- |
| 正常启动 | 品牌、正在打开工作台、一条往复指示线。减少动态效果时显示静态线 | 当前窗口的静态 HTML 首屏，等待 React 实际提交界面。首次渲染后自然离开 |
| 等待较久 | 保留原画面并提示本次启动较长 | 以实际等待时间出提示。诊断保留在启动日志中 |
| 启动失败 | 失败说明和可以键盘激活的重试按钮，停止等待指示 | 仅在确认渲染入口加载失败后提供恢复操作。重新载入通过已有窗口路径执行，渲染进程崩溃继续走现有主进程提示 |

加载页与欢迎页共享背景方向和字体，打开文件项目后的恢复和索引状态继续由各自流程展示。初始化完成即交还窗口，允许短启动直接进入内容。加载时避免阻塞窗口关闭。状态文案用可读文本表达，减少动态效果时等待含义保持完整。

## 标识评审

- 折页 N 与开页构成一个轮廓。暖金菱形在大尺寸上可单独读出火种，缩到 16 px 时主要依赖粗实的 N。任务栏和标题图标使用已有简化版，显示在稿纸上的大标识使用 SVG 主稿。
- 主图标的暖白 N 和苔绿色底有约 7.33:1 的亮度对比。深色表面交付透明反白版，保留带品牌底的主图标用于启动。独立苔绿标识叠在 V3 深色外壳上的对比约 2.27:1。
- ICO 内含 16、24、32、48、64、128、256 像素七档。正式替换时核对 Windows 安装程序、任务栏和资源管理器的实际图标，并生成和验证 macOS 所需图标。品牌源稿由评审人确认后纳入正式资源。

## 接入检查

- [ ] 在现有根入口 `index.html` 接入静态加载页，复用本地且随包分发的资产。让 Electron 的初始底色和窗口控件底色衔接第一帧，保持现有 CSP、窗口关闭与文件加载路径。
- [ ] `public/theme-init.js` 在 head 中提前应用主题与读取语言。现有脚本在首屏元素创建前尝试查找状态行，正式接入时将加载文案更新放在元素出现后。保持 `window.__VELA_HTML_READY` 给 React 启动日志使用。
- [ ] 覆盖快速启动、受控慢启动、失败后重试和渲染进程崩溃。Windows 包确认真实首帧、主题无明显白闪、最小窗及 150% 缩放下的文案与焦点。样板页面的状态、外观和语言选择器用于独立走查。

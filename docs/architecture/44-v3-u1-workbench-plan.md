# V3 U1 工作台施工与交互验收

**目标**。把 V3 的构建态、写作态与搭档入口接到正式工作台。作者切换布局后可以继续编辑同一处正文，并找回之前的面板和任务。

**实施条件**。按第 42 号计划第 0 节确认后端交接版本及本批适用的项目类型。开始前保留一份隔离项目和本批基线包，用同一章做前后对照。[总计划](42-v3-frontend-delivery-plan.md)、[U0 基线](43-v3-u0-baseline.md)

## 画面与操作状态

| 状态 | 页面应呈现的内容 | 可达行为 |
| --- | --- | --- |
| 构建态 | 顶部显示作品及两态选择，左侧是项目导航，中间是文档，Agent 和底部区域按作者原有配置显示 | 从写作态返回后恢复原有面板开关、视图、尺寸以及当前正文标签 |
| 写作态 | 正文占据中心，项目上下文和任务区默认收起。标题、切换状态和搭档入口保持可见 | 从标题区或命令面板召回同一搭档会话与任务。第二次打开时继续使用本次会话的上下文和进度 |
| 正文有未保存输入 | 正文状态在两态中持续可读，当前行、选区和滚动位置保持 | 切换后直接继续输入，撤销和重做仍对应原操作。键盘启用切换控件后有可见焦点 |
| 窗口较窄或内容放大 | 以可用内容宽度整理工具区。正文、当前模式、保存状态、召回和缩放入口优先保留 | 逐项核对模式选择、正文保存、搭档、任务和缩放入口的中心可命中且能用 Tab 到达。展开的浮层能按 Esc 关闭并归还焦点 |
| 专注模式 | F11 继续临时收起工具区域，退出后回到原工作状态 | 构建态和写作态各跑一次 F11 往返，核对面板及正文焦点 |

画面对照从 V3 原型的 `.program-window` 与 Storybook 的 Forge、Compose 出发。先对齐标题位置、稿纸与工具区的主次、拉开与收起时的反馈。颜色、圆角、留白和字体使用应用的现有语义令牌。工具栏可见动作随宽度调整时，桌面单图标按钮的命中区至少 32×32 CSS px。[V3 原型](../ui-redesign-v3/index.html)、[样板入口](43-v3-u0-baseline.md#操作样板)

## 施工顺序与回归

### 1. 抽出工作台布局，保持当前桌面行为

- [ ] 在 `App.tsx` 保留应用启动、快捷键与全局对话框的接线，将四区与分隔条的组合交给 `src/components/layout/WorkspaceLayout.tsx`。保持窗口可拖拽区域、原生控件留位和窗口缩放入口。
- [ ] 复用现有面板尺寸存储和 `closeIfAtFloor` 的松手关闭语义，明确 CSS 像素下限。以同一隔离项目前后对照左栏、搭档和底栏的打开、收起、调宽和调高。
- [ ] 用已有编辑区回归和桌面脚本确认拖拽、装载顺序及连续挂载。失败例包括侧栏拖动中提前卸载、恢复后丢尺寸、仅切面板就导致正文光标跳转。

### 2. 接入构建态与写作态

- [ ] 在 `layout-store.ts` 扩展布局状态并在 `layout-store.test.ts` 先覆盖旧偏好、切换和重新加载。持久化键兼容旧记录，缺省工作状态沿用构建态。写作态临时召回面板时，构建态的开关和尺寸偏好各自保留。
- [ ] 布局按工作状态推导显示区域，编辑器以稳定文档身份挂载。覆盖从已自定义的布局切换、写作态召回 Agent 或任务、返回原布局、重启恢复，以及 F11 叠加。
- [ ] 在构建态编辑后切到写作态，验证选区、滚动、输入、撤销和重做。保存、关闭或重开由项目现有用例处理，检查动作完成后回到同一份文档。

### 3. 接通 V3 入口与键盘路径

- [ ] 标题区复用现有分段控件，使用三语名称和按下状态。命令面板通过同一布局动作切换。快捷键在 `shortcut-store.ts` 统一注册，先核对 Windows、macOS 和用户自定义冲突，再确定默认绑定。
- [ ] 在现有左右工具栏和底部区复用搭档与任务入口。可见动作的文案、焦点顺序和点击结果相符。通过 `CommandPalette.test.tsx` 和 `shortcut-store.test.ts` 覆盖切换和绑定冲突。
- [ ] 调整 `StatusBar.tsx` 的窄窗优先级，保留可见的缩小与重置入口，将次要状态收纳到现有入口。用俄语最小窗、125% 到 150% 应用缩放，分别用鼠标和键盘恢复到 100%。
- [ ] 手测从正文、导航按钮、Agent 输入框分别切换。当前焦点所在区域收起时导向可见的模式或召回入口。打开并关闭窄窗浮层后检查焦点归还、背景滚动与 Escape。

### 4. 真机交付

- [ ] Windows 打包版比对构建态、写作态、搭档召回及未保存正文四组画面。沿用长章名和运行中 Agent 的测试稿，覆盖三语、四主题和 100%/125%/150% 应用内容缩放。通过对应设备核对 Windows 系统缩放、macOS 原生控件及中文输入法。
- [ ] 对最小窗 1024×640 和 1440×900 截图，记录实际 CSS 视口、区域宽度与交互命中。已登记的正文修稿、审稿和定稿裁切由 U2 复测。U1 验收模式、搭档、任务、窗口与正文入口的可达性。
- [ ] 完成「打开作品 → 写入未保存正文 → 往返切换 → Ctrl+S / Cmd+S → 关闭 → 重开」并回读正文。将已验的平台、代码提交、包版本与截图写入验收记录。

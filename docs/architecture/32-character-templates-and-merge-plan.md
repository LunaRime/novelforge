# C3 角色模板与重复角色合并

2026-11-12，基线 `4445a83`。承接 [18 总计划](18-followup-implementation-plan.md) 与 [31 角色事务](31-character-edits-transaction-plan.md)。

## 任务 1　模板资源和编辑会话

- [x] 保留应用级 `templates:list/get/save`，角色组件经专用适配器访问。模板以文件名定位，显示 JSON 中的模板名。列表错误与空列表分别显示。并发保存使用独立临时文件，失败清理本次临时文件。
- [x] 模板只读写可复用的档案字段。角色 UID、名称、别名、结构化和旧版关系、出场记录、生命周期与当前状态归属具体角色。旧模板内这些字段在应用时忽略。
- [x] 确认与模板读取绑定项目会话、选择和编辑快照。中途换卡、同路径重开、继续输入或卸载组件时保留当前编辑。一条 store 操作应用模板补丁，继续使用 C2 保存流程。

## 任务 2　重复角色合并

- [x] 保留疑似重复提示与手动选择目标入口。确认前读取当前数据库中的两张卡并显示合并方向与保留规则。两张参与卡有待保存编辑时提示先保存，其他角色草稿可保留。
- [x] 使用单条 `db:character-merge` 携带 C2 连接 token、目标与来源快照。在事务内校验两张卡，保留目标 UID、非空档案原文、别名与生命周期，沿用原标签、出场及更核心定位规则。同步重定向、去重结构化关系和蓝图中的旧名称、旧 UID，故障时全部回滚。
- [x] 使用事务回执更新角色投影。其他角色的未保存编辑保留原基线，下一次保存仍能识别并发冲突。已打开的蓝图编辑器同步重定向引用并保留未提交的字段。活页夹刷新失败保留当前列表并提供重试，文件树刷新失败独立反馈。取消确认或旧会话不发出写入。

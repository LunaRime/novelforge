# 安全政策 / Security Policy

## 支持版本

安全修复以 [最新稳定发布版](https://github.com/LunaRime/novelforge/releases/latest) 为基准。如果问题出现在旧版本，请同时注明受影响的版本，以及你是否在最新稳定版确认过。

## 私下报告漏洞

请通过 [GitHub 私下漏洞报告](https://github.com/LunaRime/novelforge/security/advisories/new) 提交安全问题。涉密细节、验证材料和后续沟通请留在该私密报告中。

- 附上 NovelForge 版本或提交、操作系统和受影响的功能。
- 描述触发条件、可观察到的行为，以及可能影响的数据或权限。
- 如需附日志或截图，请先移除 API 密钥、令牌、账号资料、私人书稿和可识别路径。尽量使用测试数据。

一般异常、文档问题或改进建议可通过 [公开议题模板](https://github.com/LunaRime/novelforge/issues/new/choose) 提交。

## Supported releases

The [latest stable release](https://github.com/LunaRime/novelforge/releases/latest) is the baseline for security fixes. If you found a problem in an older release, include the affected version and whether you confirmed it on the latest stable release.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/LunaRime/novelforge/security/advisories/new). Keep sensitive details, supporting materials, and follow-up in the private report.

- Include the NovelForge version or commit, operating system, and affected feature.
- Describe the conditions, observed behavior, and possible impact on data or permissions.
- Remove credentials, account information, private manuscripts, and identifying paths from logs or screenshots. Use test data where possible.

For ordinary bugs, documentation issues, and feature requests, use the [public issue templates](https://github.com/LunaRime/novelforge/issues/new/choose).
